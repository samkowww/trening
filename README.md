# Plán do finále

Tréningový plán s 3D ukážkami cvikov a denníkom tréningov.

- Web: https://samkowww.github.io/trening/
- Dáta z denníka sa ukladajú do súkromného repozitára `samkowww/trening-data` (súbor `workouts.json`).
- Prístupový kľúč sa vkladá v aplikácii (Denník → Pripojenie ku GitHubu) a ostáva len v danom zariadení. V tomto repozitári nie je žiadny kľúč ani dáta.
